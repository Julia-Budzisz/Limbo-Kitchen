# Limbo-Kitchen
**Limbo Kitchen** is a 3D, TPP, cooking-management game with a dark comedy twist. You play as a chef who signed a job contract without reading the fine print – and now, even after death, you’re bound to serve in the same restaurant. The game focuses on preparing complex dishes based on customers' visual cues and dialogues.

> **Status:** Active development (6 months in). I joined the team in the 4th month to streamline the process and implement core systems.

## ⚡ Key Contributions & Features

* **Modular Tutorial System:** Designed and implemented a scalable "Quest & Objective" architecture using Scriptable Objects. This allows for easy creation of tutorial sequences without hardcoding logic into the scenes.
* **Game State Management:** Developed the core GameManager to handle transitions between Tutorial and Gameplay modes, ensuring system-wide stability.
* **System Integration:** Extended existing team-made managers (NPC, Camera, Input) to support tutorial-specific behaviors like state skipping, forced NPC spawning, and input locking.
* **Recipe Book (In Progress):** Currently architecting a dynamic recipe system to help players navigate the complex cooking requirements.
* **Scrum Management:** Serving as the team's Scrum Master, facilitating sprints, managing backlogs, and ensuring smooth communication within our 5-person group.
* **Marketing Strategy:** Developing the game’s market presence and branding strategy.

## 📍 The Process

I joined this 5-person team during the 4th month of development. My first challenge was to quickly integrate with an existing codebase and take over the responsibility of creating a comprehensive *utorial System.

Instead of a linear, hard-to-maintain script, I built a **Modular Objective System**. By using Scriptable Objects, I created a library of "Objectives" (like *MoveToPosition*, *CookDish*, or *KickCustomer*) that designers can now chain together to create complex tutorials. This significantly decoupled the tutorial logic from the main gameplay scripts.

As a Scrum Master, I introduced more structured sprint cycles, which helped the team maintain focus during the mid-development crunch. My role bridges the gap between technical implementation and project organization, ensuring that our designers' visions are translated into optimized code.
